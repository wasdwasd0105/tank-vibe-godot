一、游戏特征：

  　平面坦克射击类游戏，具有４种加强型武器、２种附加能力、４个速度级别、４个武器级别、２０种宝物，４类１６种敌人坦克，５种难度选择。敌人具有主动进攻金鹰（基地）的智能（由难度定）。

  　能在 640Ｘ480Ｘ16 bits 下流畅运行。绿色软件，无须安装。



二、游戏目的：

  　保护金鹰（基地），消灭所有敌人坦克。



三、联网游戏：(*) 

    在封面点击 [单机游戏]，开始一个单机游戏。

    在封面点击 [联网游戏]，开始一个联网游戏。

    在点击 [联网游戏] 后，游戏弹出一个向导，用于通讯设置。如果您使用LAN 联网，可以选择“IPX 连接”或“Internet TCP/IP 连接”；如果您使用互联网联网，可以选择“Internet TCP/IP 连接”。

    您应该让网络速度最快的计算机做主机，选择“开始一个新游戏”，输入游戏名称和玩家名字，点击 [完成]；然后其他（最多 3 台）计算机做客户机，选择“加入一个己经开始的游戏”，输入主机的 IP 或域名；接着计算机会连接主机，下载游戏列表，选择该游戏名称并且输入玩家名字，点击 [完成]。

    如果两个计算机之间通过了虚拟IP网络网关，就很可能无法得到游戏列表。（谁想到怎样设置 DXPlay 可以解决这个问题，给我来信）

    您可以在任何时间加入主机的游戏，即使游戏已经开始。在加入游戏后，您就可以看见主机的游戏画面，如果主机允许您控制并且坦克没有人在控制（还没有投币或主机终止坦克的控制），您按对应的 [射击] 就可以控制该坦克。比如：主机控制着一号坦克，您应该按二号坦克的 [射击]。


四、联网游戏时的选项：(*) 

    在联网游戏中按 [F9] 可以看到“联网”一页，主机可以控制其中的选项。
比如：您要踢走一个玩家，就按下该玩家的名字；您要禁止新玩家进入，就按下 [新玩家] 的按钮；您要一个玩家终止或禁止对二号坦克的控制，就不选名字后面的 [控制P2] 检查筐；您要后来的玩家都只能观看游戏，就不选 [新玩家] 后面的 [控制P1]、[控制P2] 检查筐。这些选项在点击 [OK] 后才生效。客户机中显示的“联网”选项跟主机的同步。

    在联网游戏中，调节客户机的“杂项”不起作用，调节客户机的“性能”不起作用。（“影子不透明度”除外）

    还有，您可以根据网络速度调节主机的“性能”一页中的“网络速度”，网络慢就左调，网络快就右调。最后，关闭主机的“使用半透明的屏幕指示”可以加快游戏速度。

一、准备阶段
将TANK目录下的Stage.dat文件(事先做一个备份吧。我的做法是把最初梁先生的那个改做Stage0.dat，后来的叫Stage1.dat等等)COPY到编辑器的目录中(我认为编辑默认的就是编辑Stage.dat) 
说明：通常情况下，打开这个编辑器，鼠标默认的是select Tool。你可以用鼠标左键点击Box Tool，后就可以插入“ 
单元”(我不知用“单元”这个词是否符合梁杰峰先生的叫法。我说的“单元”所指的可以是河流、草木、冰面等甚至是敌坦克)了。这里要注意show all layer需按下去，show Gird也可以(不)按下去。(后见“编辑阶段”)
二、编辑阶段
1、看到“EC=16”按钮了吗？我理解它是敌坦克数量，关于详细的内容你进入后就自然明了(注意最左下角的“红色”坦克，它的特点是击中一炮就毙命---可是它带有好东东啊!所以我总是把它的数量搞多一些)。
2、在“EC=16”按钮的下面是一个小窗口，其实是“某关”。你可以把它在“0”的时候点击一下“Load”键，会发现就是我们平时玩的最后一关；把它在“1”的时候点击一下“Load”键，会发现就是我们平时玩的第一关。我的做法是修改每一关的地图。设完之后，就可以点击“save”进行保存后，关闭。然后你就把这个Stage.dat文件覆盖原目录下 
面那个，再运行游戏瞧吧!

十一、问题解答

游戏手柄：在安装游戏手柄之后，进入游戏后如果手柄不起作用的话，有如下解决方法： 

1、将“控制”-“游戏杆编号”选框中的数字由“0”到“16”逐个尝试，就能找到对应的值----本人开始曾以为一定是一个是“1”而另一个是“2”，后来才发现此法(我当时是将其中一个设为“1”，另一个设为“0”就好了)。 

2、如果仍然不成功，就将“控制”-“游戏杆编号”下的两个选框全都设为“0”； 
然后勾选“游戏杆选项”的其中一个“使用”的复选框即可(如果想同时安装两个手柄的话，则先按上述方法将其中一个设为“1”，另一个设为“0”逐一完成)。我将两个“使用”全选中之后就出现了一个手柄同时控制两辆坦克的“一切行动听指挥”的步调一致局面! 

3、如果这个方法仍不可行，我想可能是界面设置上还有点儿小问题(注意：“DXinput驱动”项的使用问题，可以再试 
一下全选和全不选的效果----我成功的设置是全不选---我目前还不清楚这个选项的功能)。(【DXinput驱动】选项是 
控制使用什么方式的驱动手柄/键盘。Checked是使用DXinput连接；unChecked是使用WindowsAPI连接。如果你的手柄驱动程序跟XInput不完全兼容，那就只得使用WindowsAPI了。------清风) 

4、(我的同事们已经都安装了游戏杆----从价格上讲十几元钱的到上百元钱的都成功了)玩家朋友别灰心!

LV0的地雷是普通的外观，LV1的地雷外观是周围有8个小黑点儿，LV2的地雷外观是带有闪烁的彩环。
我认为“有时候经常稀里糊涂就死了”主要是由于敌方也布雷!这种地雷(Mine)的特点是当我方坦克驶近雷区时，敌方

：用装备了“海之记忆(Memory of Sea)”的战车快速引爆敌方的地雷)



关于两种宝物的补充：
Shield Of Moon: 
上半部分无敌，但火焰除外。它至少能挡住一发穿甲弹；如果穿甲弹的威力可以破钢（HitCount>=6），那么Shield Of Moon就会消失，同时坦克获得 1.5sec 的无敌时间。Lv0 Mine（GunLevel＝0时释放的地雷）只能引起爆炸伤害，所以对Shield Of Moon无效。

Memory of Sea:
被攻击时、死亡时 武器级别和特殊武器不会掉。（这也是为什么叫Memory的原因）一般情况下，如果佩戴其他辅助选件，受损就会掉选件；无佩戴选件，受损就会掉武器级别。Memory of Sea可以保你顺利升级到(并保持)MAX。

另外，LV1和以上的 Mine（可以看见 Mine 四周有八个小点）
可以使得坦克底盘损坏，以致移动速度下降。解决方法就是：
1、自己获得一个金色的宝物；
2、自己或者其他友方获得一个 MAX 隐藏宝物；
3、佩戴 Memory of Sea 。

LV2和以上的 Mine（可以看见 Mine 中心是红色的）可以把坦克扎飞，下落时会对下落位置的任何一方造成损坏。解决方法就是：
1、佩戴 Memory of Sea（但一样要受伤）

还有，佩戴【AntiSkid】（防滑板）可以更早地发现 Mine，并且可以在敌方 LV0～LV2 的 Mine 上安全行走（LV3 的Mine 是有彩环的）。

关于联网：
【联网：如果你和你的朋友都有 ADSL】

如果你和你的朋友都有 ADSL 并且都不是小区网络，（在同一个房间或同一个小区网络另算）你就可以尝试联网。（在公司的 LAN，从机速度跟主机一样） 

=================================================================== 

联网步骤： 

【主机】 

1) 在封面点击 [联网游戏]，开始一个联网游戏。 
2) 在点击 [联网游戏] 后，游戏弹出一个向导，用于通讯设置。如果您使用LAN 联网，可以选择“IPX 连接”或“Internet TCP/IP 连接”；如果您使用互联网联网，可以选择“Internet TCP/IP 连接”（通常是这个）。 
3) 选择“开始一个新游戏”，输入游戏名称和玩家名字，点击 [完成]。 
4) 如果你用“Internet TCP/IP 连接”，可以按 [F9] │ [联网]页 │ [? 信息] 按键，看看主机的 IP 。 


【从机】 
1) 在封面点击 [联网游戏]，开始一个联网游戏。 
2) 在点击 [联网游戏] 后，游戏弹出一个向导，用于通讯设置。主机用什么从机就用什么。 
3) 选择“加入一个己经开始的游戏”。如果你用“Internet TCP/IP 连接”，在弹出的输入框输入主机的 IP 。 
4) 接着从机会连接主机，下载游戏列表，选择该游戏名称(要点中)并且输入你的名字，点击 [完成]。 

------------------------------------------------------------------- 

这样联网就大功告成。你在单机如何开始游戏，就如何开始游戏。记得有一半的键盘是你的同伴控制的。更详细的请看 readme.txt ，有一段很长的说联网的。

1各种武器和装备
=========================================================================================================
1、普通子弹
坦克速度和子弹级别越高越好用，全是3级时极猛；级别不够时一般只是用于对付A1/2及B1时还比较有把握。
2、密集子弹
最普通，级别高后一般不用。1、2级还好，3级的子弹太散，宜在开阔地狂扫，这样的效果有时也很惊人。
3、爆破弹
威力较强，但是如果有燃烧弹或者穿甲弹很少会选它，使用方法必须自己体会，一般需要分两次解决较难对付的坦克。
4、燃烧弹
我很喜欢，有了它在地形较为狭窄的地带简直是棒极了，先放火，然后用密集的普通子弹打击很快就会将来者解决。
5、穿甲弹
不用多说了吧？因为它是最简单的武器，只要命中目标，无论什么坦克都必死，运气好的话可以一次穿掉几个，对枪你也绝对不会吃亏。
6、防滑装
千万别以为它是可有可无的，在冰上行动时如果还要对敌的话，你就会明白它的好处了。如果没有，最好少在冰面上行走。
7、渡水装
一般我总是配备着的，因为没它太不方便了，毕竟没有几关没有水。

附件：(转自坦克主页的作者留言)
大家好，我是论坛管理员，也是zairwolf。坦克的主页就是我做的。今天刚刚整理了一下坦克主页的留言本。想到了很多，在这里和大家交流交流。 
   梁杰峰，也就是决战坦克游戏的作者。我只是帮他做了一个决战坦克的主页。赤兔，是一个热心网友，也是坦克游戏的忠实爱好者，用户问题的解答基本上都是他处理的。我们三个基本上就是坦克游戏比较重要的人了。先介绍一下我们几个的情况。 
   梁杰峰。当时认识他是在网上发现了这个小游戏之后，因为这是我所发现的最好的坦克游戏，让人回味过去。所以我就想做些什么能帮忙的。我比较懂一点主页制作，而我觉得这样一个优秀的游戏是需要有一个官方网站，也方便大家交流以及新版本发布，所以就联系了梁杰峰，这样认识的。当时他还是西安交大的大四学生，所以还算比较有时间制作更新这个软件。当时用户的很多建议，都是那时实现的。坦克网站也是那时建立起来的。后来梁先生毕业工作，到了珠海金山软件公司。众所周知那是很忙的，尤其作为一个新员工，工作量是非常大的，所以我就很少见到他在网上了，而且决战坦克的更新就慢了下来。他的大体情况就是这样。由于忙，也就比较少处理大家的问题，一般都是赤兔处理。 
   我呢，现在尚未毕业，在广州华南理工大学上大四。也就是说，今年夏天就毕业了。现在已经很忙了，因为自己学习的问题，所以可能不能按时毕业，找工作上可能因而会有一些波折了。网页的更新也就这样耽搁下了。曾经想过把坦克首页改版一下，界面让它更清新，内容更丰富，浏览更直观。但是我美工不行，而且现在要找工作了。一个人做这些事情是很累的，正如梁杰峰一个人制作新版本的坦克一样。今天想到清理规范一下留言本，于是就忙了一下午，差不多搞定了。而下一步，也要踏入社会，找寻工作。前途也算微茫吧。 
   赤兔，现在在北京工作。他是坦克留言和坦克论坛的主要管理员，也是心空这一片天空的主要管理员。他的文学素质也很好，人也热心。所以大家基本上的疑问他都可以及时答复。他现在是在北京工作，上网时间比较充足，所以管理也比较方便。 
   以上是我们三人的情况。下面说一下对大家玩这个游戏的一些想法和一些疑惑的解答。 
   毋庸置疑，这个决战坦克是网上现有的所有同类型游戏中最优秀的。这在我上网四五年中不断找寻这方面的游戏的经历中就可以感觉出来。这是唯一一个界面细腻、坦克逼真、双方实力均衡、最类似任天堂上的tank的一款PC游戏了。而我想以后也不会再有比它更好的同类型游戏了。毕竟，在这样一个金钱至上的势利社会，能给大家免费提供什么东西的人已经不多了。社会现在的道德水准，我想不用多说大家也明白，还有几多古道热肠的人们。 
   对于这样一个游戏，有一个最美的主页是理所当然的事情。我已经尽力了。 
   而坦克的爱好者们，也都能理解作者，也明白感恩，在提出一些建议的同时，热情赞扬这个游戏，给作者最大的鼓励。我想这是最重要的。可是有些玩家一有问题就发问，从没有静下心先看一下论坛和留言本上的问题解释和说明。我承认网页做的不够好，很多疑难问题没有直观的在网页上给大家一个完美的答复。但我想大家还是可以通过论坛来讨论和发现问题的解决方法的。同类型的问题已经让我烦不胜烦，可还是有玩家每次都那样发问。所以我干脆让问问题都到这里。 
   这样一个游戏，梁杰峰能一个人做到这种程度，已经很不容易了。而完璧微瑕也是不足为怪的。现在坦克爱好者反映的坦克的问题，大体有三个：第一、死机问题；第二，手柄问题；第三，推出新版本的时间。 
   关于死机，毕竟每个人的电脑配置不同，软件环境也不同，而且坦克本身也有一些bug，所以会造成这种结果。这个梁杰峰已经注意到了，他也在寻找原因。 
   至于手柄问题，我不想多说，赤兔已经回答的够多了，有人不能静下心来看，怪不了别人。 
   关于新版本，我在前面说明了，现在不是学生时代，梁杰峰可以有那么多时间和精力去开发推出。毕竟这是一个免费的游戏。有些网友说可以进行廉价的收费。我想这是不可取的。一则不方便，二则这个游戏是为了大家的快乐，童年的快乐，收费的话味道就变了。不管多少。当然如果其他一些软件公司想集成坦克在他们的软件中，这也是梁杰峰可以考虑的。 
   其他的，大多就是比较琐碎的了。不过有一个比较突出的问题就是，有些网友想得到决战坦克的源代码。不可否认，很多是为了研究之用。但有些人居心叵测，我们只是不愿说罢了。得到源代码能做什么，众所周知，可以随意开发。而他们中的有些，得不到源代码，就把现有的修改一些鸡毛，当成自己的收费软件去卖。更有甚者，利用大家企盼新版的特点，加入病毒放在软件园发布。为了广大坦克游戏爱好者的利益，梁先生也不会随意给他人源代码的。关于新版本发布，我想大家知道官方网站是最权威的了。这我就不多说了。 
   看到以前很多玩家的留言，说道他们玩坦克的欢乐，也不禁为他们展颜。是啊，这个游戏给了我们多少欢乐。有一句话，知足常乐。我想我们应该学会感恩。 
   就说这么多了。祝大家玩的愉快。也欢迎大家提建议和意见，集思广益。
